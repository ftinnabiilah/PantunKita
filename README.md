# PantunKita — Pantun Caption Assistant for Social Media
**Pantun Verse Digital Solutions (CSC575 - Group T5CDCSS230 6B1)**

## Struktur Fail Sistem
1. `index.html` — Antara muka utama (Halaman **Cipta**, **Kegemaran**, dan tetingkap **Tentang / Apa itu pantun?**).
2. `style.css` — Reka bentuk responsif bertemakan Batik & Tradisional Melayu (mengikut Rajah 4, 5, dan 6 dalam Laporan Projek).
3. `app.js` — Logik penapisan acara (`FR-01`), nada (`FR-02`), carian kata kunci (`FR-03`), fungsi salin teks (`FR-05`), pengurusan kegemaran `localStorage` (`FR-06`, `FR-07`), dan pengendalian ralat (`NFR-04`).
4. `dataset.js` & `pantun_dataset.json` — Pangkalan data 990 pantun 4 kerat yang telah dikategorikan mengikut `acara`, `nada`, dan `kata_kunci`.

## Cara Menjalankan Sistem
1. Ekstrak kesemua fail ke dalam satu folder yang sama.
2. Klik dua kali pada **`index.html`** untuk membuka aplikasi terus di pelayar web (Chrome, Edge, Safari, Firefox) tanpa memerlukan pelayan tambahan.
3. Untuk memuat naik ke internet secara percuma (Milestone 6: Deployment), muat naik folder ini ke **GitHub Pages**, **Netlify**, atau **Vercel**.
